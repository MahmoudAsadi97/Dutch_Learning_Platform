# Narrated story practice

Video creation is retired. The application does not invoke a video rendering provider, and all historical
video mutation endpoints return HTTP 410. Existing records and owner-scoped media remain readable for
historical data export; no destructive migration is required. Old video page links open the Stories library.

The replacement uses the existing story and speech features: level-filtered authored stories, optional
sentence playback, comprehension questions, vocabulary use and retelling. It adds no video service.
